📱 Galaga: A Flutter Mobile Game
Group 4 – BSCS
Pamantasan ng Lungsod ng Muntinlupa (PLMun)

🔰 Overview
Galaga is a mobile application developed using Flutter, inspired by the classic arcade shooting game. This project is part of our Mobile Application Development course requirement. The primary goal is to design and implement a functional and interactive mobile game while applying Flutter development best practices.

🧩 Project Structure & Development Plan
This project is implemented following the structured development plan provided by our professor, ensuring a professional and systematic approach:

✅ Phase 1: Project Setup
Initialized Git repository and hosted on GitHub.

Established branching strategy (main, develop, feature/*).

Installed Flutter SDK and added to environment PATH.

Set up Android Studio and required plugins (Flutter & Dart).

Configured emulators and real devices for testing.

Ran flutter create galaga to generate the base project.

Committed initial setup to the repository.

🖼️ Phase 2: Basic Layout and UI Design
Used Container, Row, and Column for structural layout.

Built the home screen using Scaffold.

Implemented scrollable UI using ListView.

Designed UI elements like AppBar, FloatingActionButton, and Drawer.

Followed Material Design guidelines for consistent UX.

🔄 Phase 3: Add Interactivity and Navigation
Defined routes in MaterialApp for screen navigation.

Used Navigator.push and Navigator.pop for routing.

Implemented tap gestures using GestureDetector.

Added interactivity through buttons and swipe actions.

✨ Phase 4: Enhance with Animation
Used Flutter animation widgets like AnimatedContainer, AnimatedOpacity.

Implemented smooth transitions and visual feedback.

Used AnimationController and Tween for advanced animation effects.

🧪 Phase 5: Testing and Finalization
Conducted unit and widget testing using Flutter’s test framework.

Debugged and fixed functional issues during development.

Finalized app metadata (name, version).

Prepared release builds and tested deployment on devices.
